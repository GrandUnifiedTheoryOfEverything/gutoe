# Documentation Index

Canonical documentation for the Grand Unified Theory of Everything
(GUToE) project — a pedagogical and computational framework for the
standard actions of fundamental physics. Start with
[THEORY.md](THEORY.md) for the formal content or
[USER_GUIDE.md](USER_GUIDE.md) to run things.

| Document | Content |

| [THEORY.md](THEORY.md) | Formal apparatus: conventions, Definitions 1–5 (composite action and sectors), Remark 1 (gravity programs), Propositions 1–4 (computed results), Open Problems 1–5 |

| [GUT_EMBEDDING.md](GUT_EMBEDDING.md) | SU(5)/SO(10) embedding of the Standard Model, normalization and anomaly arithmetic |
