# Legacy documentation

The files in this directory are the project's pre-2026 documentation,
superseded by the restructure that followed the independent academic
evaluation (see the repository root PDF and `docs/CONCLUSION.md`). They
are retained unmodified for history and provenance. The current canonical
documentation lives in `docs/` — start at `docs/index.md`.

Known issues preserved here uncorrected include: the unitless (and
slightly off) cosmological constant, the gravity sector presented as
summable alternative formulations, and "theoretical implications" stated
as results. See `docs/CONCLUSION.md` §3 for the full list and where each
is fixed.
